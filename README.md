## Mistar KE Phones E-Commerce Website

### Overview
Mistar KE Phones is an e-commerce platform focused on selling Apple products. The platform provides a clean shopping experience with structured product displays and secure transactions.

### Features
- Product catalog for Apple devices
- Clean and modern UI design
- Secure checkout process
- Mobile-friendly interface

### Key Systems Implemented
- Payment integration via Pesapal
- Authentication system using Django Allauth
- Backend product management system

### 🛠 Tech Stack
- Backend: Django (Python)
- Frontend: HTML, CSS, JavaScript

### Live Website
👉 https://mistarkephones.co.ke
